# بناء واجهة مستخدم

تحتوي `sci_etl_core.discovery` على نموذج القراءة الذي تعرضه طبقة العرض:
`DiscoveryResult` (نص الاستعلام ورقاقاته، والنتائج المدموجة، والرسم البياني،
والأوجه، وعدد المطابقات، والوقت المنقضي، وفروع البحث المتدهورة والمتخطّاة)
و`Facet`. كلاهما صنف بيانات مجمّد (frozen dataclass)، واستيراد الوحدة لا يحمّل
أي مخزن ولا أي آلية لحلقة الأحداث ولا أي اعتمادية اختيارية.

اعرض `FusedHit.snippets` بترميزك الخاص انطلاقًا من `highlights` الخاصة بها،
سطرًا واحدًا لكل حقل، ووسِم النتيجة التي يكون `lexical_rank` فيها `None` بأنها
مطابقة بالمعنى. وابنِ المدرّجات التكرارية للتواريخ أو السنوات من `range_counts`،
التي تُبقي كل الفئات ظاهرة أثناء تحديد إحداها.

أبقِ تحليل الاستعلام متزامنًا مع كل ضغطة مفتاح، واجعل الاسترجاع وحده غير
متزامن: أخِّره قليلًا (debounce)، وألغِ البحث عندما يبدأ بحث أحدث، وتجاهل أي
نتيجة تصل بعد بدء بحث أحدث.

قبل مشاركة المخازن بين واجهة مستخدم وعمليات الاستيعاب، اقرأ
[ملكية المخازن](store-ownership.md).
