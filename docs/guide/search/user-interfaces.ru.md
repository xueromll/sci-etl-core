# Создание пользовательского интерфейса

`sci_etl_core.discovery` содержит модель чтения, которую отображает слой
представления: `DiscoveryResult` (текст запроса и его метки-чипы, объединённые
результаты, граф, фасеты, число совпадений, затраченное время, а также
деградировавшие и пропущенные ветви поиска) и `Facet`. Оба класса — замороженные
dataclass, и импорт модуля не загружает ни хранилищ, ни механизмов цикла
событий, ни необязательных зависимостей.

Отображайте `FusedHit.snippets` собственной разметкой на основе их
`highlights`, по одной строке на поле, а результат, у которого `lexical_rank`
равен `None`, помечайте как совпадение по смыслу. Гистограммы по датам или
годам стройте из `range_counts`: они оставляют видимыми все интервалы, пока
выбран один из них.

Разбор запроса выполняйте при каждом нажатии клавиши, а асинхронным делайте
только извлечение результатов: применяйте задержку (debounce), отменяйте поиск,
когда начинается более новый, и отбрасывайте любой результат, пришедший после
начала более нового поиска.

Прежде чем делить хранилища между интерфейсом и запусками загрузки, прочитайте
раздел [Владение хранилищами](store-ownership.md).
