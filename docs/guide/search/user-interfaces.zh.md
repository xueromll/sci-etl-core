# 构建用户界面

`sci_etl_core.discovery` 包含表示层所渲染的读模型：`DiscoveryResult`（查询文本及其标签、
融合后的命中结果、图、分面、匹配数量、耗时，以及降级和跳过的检索分支）和 `Facet`。
两者都是不可变的 dataclass，导入该模块不会加载任何存储、事件循环机制或可选依赖。

请根据 `FusedHit.snippets` 的 `highlights` 用你自己的标记来渲染它们，每个字段一行；
对于 `lexical_rank` 为 `None` 的命中结果，将其标注为按语义匹配。日期或年份直方图可以由
`range_counts` 构建，它在选中某个区间时仍让所有区间保持可见。

让查询解析在每次按键时同步进行，只把检索做成异步：对检索做防抖（debounce），在新的检索
开始时取消旧的检索，并丢弃在更新的检索开始之后才到达的任何结果。

在界面和摄取运行之间共享存储之前，请阅读[存储的所有权](store-ownership.md)。
