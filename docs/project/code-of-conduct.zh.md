# 贡献者公约行为准则

## 我们的承诺 {#our-pledge}

身为社区成员、贡献者和领导者，我们承诺：无论年龄、体型、可见或不可见的残疾、族裔、性征、
性别认同与表达、经验水平、教育程度、社会经济地位、国籍、个人外貌、种族、种姓、肤色、宗教，
或性认同与性取向如何，每个人参与我们的社区都不会受到骚扰。

我们承诺以有助于建立开放、友善、多元、包容和健康社区的方式行事和互动。

## 我们的准则 {#our-standards}

有助于为我们的社区营造积极环境的行为示例包括：

* 对他人表现出同理心和善意
* 尊重不同的意见、观点和经历
* 提出并虚心接受建设性的反馈
* 承担责任，向受我们的错误影响的人道歉，并从经历中学习
* 关注的不仅是对我们个人最好的事情，而是对整个社区最好的事情

不可接受的行为示例包括：

* 使用带有性意味的言语或图像，以及任何形式的性关注或性挑逗
* 恶意挑衅、侮辱或贬损性的评论，以及人身攻击或政治攻击
* 公开或私下的骚扰
* 未经他人明确许可，公布其私人信息，例如住址或电子邮件地址
* 在专业场合中可被合理视为不当的其他行为

## 执行责任 {#enforcement-responsibilities}

社区领导者有责任阐明并执行我们关于可接受行为的准则，并将针对他们认为不当、具有威胁性、
冒犯性或有害的任何行为，采取适当且公正的纠正措施。

社区领导者有权利也有责任删除、编辑或拒绝不符合本行为准则的评论、提交、代码、维基编辑、
议题以及其他贡献，并会在适当时说明其审核决定的理由。

## 适用范围 {#scope}

本行为准则适用于所有社区空间，也适用于个人在公共空间中正式代表社区的场合。代表社区的示例
包括使用官方电子邮件地址、通过官方社交媒体账号发布内容，或在线上或线下活动中担任指定代表。

## 执行 {#enforcement}

辱骂、骚扰或其他不可接受行为的事例，可以通过 lanhua1122333@gmail.com 报告给负责执行的社区
领导者。
所有投诉都将得到及时、公正的审查和调查。

所有社区领导者都有义务尊重任何事件报告者的隐私和安全。

## 执行指南 {#enforcement-guidelines}

社区领导者在判定他们认为违反本行为准则的任何行为的后果时，将遵循以下社区影响指南：

### 1. 纠正 {#1-correction}

**社区影响**：使用不当言语，或其他被视为不专业或在社区中不受欢迎的行为。

**后果**：由社区领导者发出私下的书面警告，阐明违规的性质，并解释该行为为何不当。可能会
要求公开道歉。

### 2. 警告 {#2-warning}

**社区影响**：通过单一事件或一系列行为构成的违规。

**后果**：发出警告，并说明继续该行为的后果。在规定期限内，不得与相关人员互动，包括不得
主动与执行本行为准则的人员互动。这既包括避免在社区空间中互动，也包括避免在社交媒体等外部
渠道中互动。违反这些条款可能导致临时或永久封禁。

### 3. 临时封禁 {#3-temporary-ban}

**社区影响**：严重违反社区准则，包括持续的不当行为。

**后果**：在规定期限内，禁止与社区进行任何形式的互动或公开交流。在此期间，不得与相关人员
进行任何公开或私下的互动，包括不得主动与执行本行为准则的人员互动。违反这些条款可能导致
永久封禁。

### 4. 永久封禁 {#4-permanent-ban}

**社区影响**：表现出违反社区准则的行为模式，包括持续的不当行为、骚扰个人，或攻击、贬低
某些群体。

**后果**：永久禁止在社区内进行任何形式的公开互动。
