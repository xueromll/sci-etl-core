# Утверждения

Все имена на этой странице импортируются из `sci_etl_core.claims`. Весь пакет
имеет статус предварительного (provisional): имя может измениться в минорном
выпуске, с записью в CHANGELOG, пока от него не зависит ни один известный
потребитель. Как части сочетаются друг с другом, показывает руководство
[Утверждения и происхождение](../guide/claims.md).
