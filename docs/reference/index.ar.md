# مرجع الواجهة البرمجية

تُولَّد هذه الصفحات من سلاسل التوثيق (docstrings) وتعليقات الأنواع في الشيفرة
المصدرية، ولذلك تظهر أوصاف الأصناف والدوال باللغة الإنجليزية. توثّق كل صفحة
الوحدات التي تعرّف الأسماء؛ استوردها من الحزمة المذكورة في أعلى الصفحة لا من
الوحدة التي تعرّفها، لأن ترتيب الوحدات داخل الحزمة قد يتغير بين الإصدارات.

| الصفحة | الحزمة | المحتوى |
|--------|--------|---------|
| [خطوط المعالجة](pipelines.md) | `sci_etl_core` | `AsyncETLPipeline` و`ETLPipeline` والاستيعاب في الذاكرة و`ShutdownSignal` وأحداث التقدم و`RunMetrics` |
| [الإعداد](configuration.md) | `sci_etl_core` | `BaseAppConfig` وأقسامه و`load_config` و`load_config_async` |
| [النماذج والاستثناءات](models.md) | `sci_etl_core` | `RawRecord` و`TokenUsage` وتسلسل `SciEtlError` ونموذج القراءة الخاص بالاستكشاف |
| [المستخرِجات](extractors.md) | `sci_etl_core.extractors` | `AsyncExtractor` ومستخرِجات arXiv وPubMed وSemantic Scholar وOpenAlex |
| [المحلِّلات](parsers.md) | `sci_etl_core.parsers` | محلِّلات PDF وLaTeX وHTML وDOCX وJATS XML، واقتطاع قائمة المراجع |
| [النموذج اللغوي](llm.md) | `sci_etl_core.llm` | عملاء النماذج اللغوية، والتخزين المؤقت للاستجابات، ومرشحات الصلة، ومستخرِجات الكيانات والمخططات المنمّطة |
| [التضمينات](embeddings.md) | `sci_etl_core.embeddings` | مولّدات التضمينات، والتقطيع، والمخازن المتجهية، والبحث بالتشابه |
| [البحث](search.md) | `sci_etl_core.search` | لغة الاستعلام، ومخازن النصوص، ودمج الترتيب، والبحث الهجين، ورسوم الاستكشاف البيانية |
| [المصدِّرات](exporters.md) | `sci_etl_core.exporters` | دورة حياة المصدِّر، ومصدِّرا CSV وJSON Lines |
| [الادعاءات](claims.md) | `sci_etl_core.claims` | الادعاءات، ومقاطع الأدلة، والأختام، ومخازن الادعاءات والرفض، ومستخرِج الادعاءات ومصدِّرها (مؤقتة) |
| [المعالِجات](processors.md) | `sci_etl_core.processors` | خطوات DataFrame، ومُطبِّعات المفاتيح، ومدقّقات السجلات ومخالفاتها، ومصارف الجداول |
| [الحالة](state.md) | `sci_etl_core.state` | مديرو الحالة القائمون على الملفات وعلى SQLite |
| [الأدوات المساعدة](utilities.md) | الوحدة التي تعرّف الاسم | عملاء HTTP، ومحدِّدات المعدل، بما فيها الحدود الخاصة بكل مضيف |

لمعرفة كيف تتكامل الأجزاء، راجع [البنية](../guide/architecture.md).
